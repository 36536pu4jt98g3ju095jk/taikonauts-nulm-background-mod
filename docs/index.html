NULM Background

演奏画面の背景に
NULM アニメーションを流そう

Play NULM animations
as your play-screen background

TaikoNauts ModLoader 用の MOD です。上背景・下背景に NULM を流し、魂ゲージがクリアになると fever 背景へ切り替わります。背景は曲ごとにランダムで選ばれます。

A TaikoNauts ModLoader mod that plays NULM animations as the upper and lower backgrounds, switches to a fever background when the soul gauge clears, and picks backgrounds at random for each song.

導入手順

Install

  1. TaikoNauts を終了します。ゲームの起動中は MOD を入れ替えないでください。

    Close TaikoNauts. Do not change mods while the game is running.

  2. リリースページから ZIP をダウンロードし、TaikoNauts\mods に展開します。mods\nulm-background ができれば成功です。

    Download the ZIP from the release page and extract it into TaikoNauts\mods. You should get mods\nulm-background.

    TaikoNauts\
  mods\
    nulm-background\
      nulm_background.dll
      modconfig.json
      config.example.json

  3. 使っているスキンの Lumens フォルダを作り、NULM のパックを置きます。パックごとに 1 つのフォルダを作ります。

    Create a Lumens folder inside the skin you use and put your NULM packs there, one folder per pack.

    TaikoNauts\
  Skins\
    K-Style\
      Lumens\
        bg_nomal_a_01\
          bg_nomal_a_01.nulm
          bg_nomal_a_01_0.png      (atlas 0)
          bg_nomal_a_01_1.png      (atlas 1, if used)
        donbg_a_01_1p\
          ...

    フォルダ名、.nulm のファイル名、画像の接頭辞は同じ名前にします。

    The folder, the .nulm file and the image prefix share one name.

  4. ゲームを起動して、曲を演奏します。背景が NULM に変わります。

    Start the game and play a song. The background becomes your NULM.

パックの名前とレイヤー

Pack names and layers

パック名の先頭で、どの場所に使うかが決まります。曲が始まるたびに、レイヤーごとにパックが 1 つランダムに選ばれます。同じレイヤーのパックが複数あれば、曲ごとに別の背景になります。

The start of a pack's name decides where it is used. At the start of every song, one pack is picked at random for each layer. With several packs for a layer, each song gets a different background.

名前の先頭Name starts withレイヤーLayer
donbg_上背景Upper background
bg_nomal_ / bg_normal_下背景Lower background
bg_fever_fever 背景(ゲージがクリアの間に表示)Fever background (shown while the gauge is cleared)
bg_dai_下背景の上に重ねる台Stand drawn over the lower background

スキンに無いレイヤーは、ゲーム本来の背景のままです。スキンを切り替えると、そのスキンの Lumens の中身に切り替わります。

A layer the skin has no pack for keeps the game's own background. Switching skins switches to that skin's Lumens.

fever への切り替え

Fever switching

魂ゲージがクリアになると、上背景が切り替わり、下に fever 背景が現れます。ゲージがクリアの位置を下回ると、元に戻ります。判定はゲーム自身のクリア判定(Gauge.IsGaugeClear)を使うので、スキンには依存しません。

When the soul gauge clears, the upper background changes and the fever background appears below. It returns when the gauge drops under the clear border. The decision is the game's own (Gauge.IsGaugeClear), so it does not depend on the skin.

ゲームの更新でコードの形が変わると、この判定を見つけられなくなることがあります。その場合は何も書き換えず、fever 背景だけ使われません(下記のログで分かります)。
A game update that changes the code can make this decision unavailable. Nothing is patched in that case and only the fever background is not used (the log below tells you).

設定(任意)

Settings (optional)

config.json はなくても動きます。スキンの Lumens に無いレイヤーに使う固定のパックや、判定方法を指定したいときだけ作ります。config.example.json を mods\nulm-background\config.json にコピーして編集します。固定のパックは mods\nulm-background\packs\<パック名>\ に置きます。

config.json is not required. Create it only to name fixed packs for layers the skin's Lumens has nothing for, or to change the detection. Copy config.example.json to mods\nulm-background\config.json and edit it. Fixed packs live in mods\nulm-background\packs\<pack>\.

{
  "upper": { "pack": "donbg_a_01_1p", "x": 0, "y": 0 },
  "lower": { "pack": "bg_nomal_a_01", "x": 0, "y": 540 },
  "fever": { "pack": "bg_fever_a_01", "x": 0, "y": 540 },
  "dai": { "pack": "bg_dai_a_01", "x": 0, "y": 540 },
  "clearDetection": "game"
}
値Value意味Meaning
"game"ゲーム自身のクリア判定を使う(初期値)Use the game's own clear decision (default)
"gauge"描画されたゲージの長さから推測する。スキンの絵に依存する代替手段Infer it from the drawn gauge length. A fallback that depends on the skin's artwork
"off"fever に切り替えないNever switch to fever

うまくいかないとき

Troubleshooting

ゲームのフォルダにある modloader.log に、この MOD の動作が記録されます。NulmBackground の行を探してください。

The mod writes to modloader.log in the game folder. Look for the NulmBackground lines.

ログLog line意味と対処Meaning and fix
Loaded the lower background "…" パックを読み込めました。曲ごとに出ます。A pack was loaded. You see this for every song.
Hooked Gauge.IsGaugeClear fever の判定が使えます。The fever decision is available.
Gauge.IsGaugeClear was not found exactly once… ゲームの更新で判定のコードが変わっています。fever 背景は使われません。MOD の新しい版を待つか、clearDetection を "gauge" にしてください。A game update changed the code. The fever background is not used. Wait for a newer release or set clearDetection to "gauge".
Could not read …\*.nulm パスが違います。フォルダ名、.nulm のファイル名、置き場所(スキンの Lumens)を確認してください。The path is wrong. Check the folder name, the .nulm file name and the location (the skin's Lumens).
Texture lifecycle extension unavailable… ModLoader が古いです。v1.2.0 以降に更新してください。The ModLoader is too old. Update to v1.2.0 or later.

背景が変わらない

The background does not change

  • Lumens を、いま選んでいるスキンの中に作りましたか。
  • パック名の先頭は donbg_、bg_nomal_、bg_fever_、bg_dai_ のどれかですか。
  • ゲームを一度終了して、起動し直しましたか。
  • Did you create Lumens inside the skin you have selected?
  • Does the pack name start with donbg_, bg_nomal_, bg_fever_ or bg_dai_?
  • Did you restart the game?

できないこと

Limitations

  • NULM の中のクリップマスクとテキストフィールドは再現しません。
  • 1P のレイアウトだけに対応しています。
  • 背景を別のサイズで描くスキンは検出できません。
  • Clip masks and text fields inside a NULM are not reproduced.
  • Only the 1P layout is handled.
  • Skins that draw their backgrounds in another size are not detected.
